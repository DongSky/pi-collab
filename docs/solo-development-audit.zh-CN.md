# 单人开发操作核查与聊天工作台验收

日期：2026-09-25。范围：右侧聊天、单人编辑到运行提交，以及新增的语义开发工具。本文不是 Cursor 全量兼容声明。

## 本轮新增并验证

- 右栏采用连续消息流、用户消息气泡、Markdown / 代码块回复、底部固定输入框。Enter 发送，Shift+Enter 换行，中文输入法组词期间 Enter 不发送。
- 文件 AI 与项目任务均可显示折叠工具结果。文件修改以 Diff 卡片呈现，确认应用仍经过最新版本检查与三方合并。
- 文件 AI 运行期间保留输入框，支持调整当前方向、完成后继续、停止和回答 AI 提问。未确认的发送保留请求编号，重试沿用原请求。
- 文件对话保留本窗口消息、草稿与运行关联；新对话可切换到最近 10 个本窗口对话。完整任务仍保存在服务端。下一轮模型携带最近 4 条对话摘要，不等于无限上下文或跨设备聊天同步。
- 选中代码后点击“选区问 AI”，会将文件路径、行号和选区加入右栏输入框，发送前仍可修改。
- 编辑器增加中文查找替换、正则 / 全词匹配、跳到行、折叠、括号匹配、多光标、矩形选区、Tab 缩进、词语补全。
- JS / TS / JSX / TSX / JSON / CSS / HTML / Python / Markdown 语言高亮；JS / TS / JSON / CSS / HTML / Markdown 支持 Prettier 格式化。首次验收使用内置默认格式；后续补充的项目 JSON / YAML 格式配置见下节。格式化期间若收到其他成员编辑，拒绝套用过期结果。
- 原子重命名 / 移动：检查来源版本与目标冲突，在同一事务中建立新路径并将旧路径标记删除。其他客户端对旧文档的写入会被拒绝。旧路径仍可显式恢复。
- 共享草稿跨文件内容搜索，点击命中跳到行列。搜索包含尚未提交 Git 的共享修改，忽略已删除路径；版本号标识查询时刻。结果最多 200 处，跳过二进制和大于 256 KiB 的文本文件，显示跳过数。搜索采用字面量匹配；后续补充的跨文件批量替换见下节。
- 整个工作文件夹 ZIP 导出：包含快照原文件以及共享草稿覆盖、新建和删除，最多 2,000 文件 / 32 MiB；使用现有受限路径和敏感内容排除规则，不带 Git 历史。不会回写最初导入的目录。
- “共编与版本 → 在终端运行此版本”将当前已保存草稿冻结并选择人工终端。用户点击“打开共享终端”后运行该版本，无需调用模型；交接状态统一称为“已交给运行工作区”。

## 单人实际操作路径

1. 打开文件夹，选择文件；左侧文件树、中央标签编辑器、右侧聊天。
2. 编辑 / 保存 / 格式化 / 重命名。必要时请求文件 AI，检查候选 Diff 后应用。
3. 在左侧“共编与版本”填写交接说明，选择“在终端运行此版本”，在右栏启动终端。
4. 在底部终端安装依赖、运行测试、编译或启动项目自己的命令行调试器。终端操作的是独立工作副本，编辑器保存不是直接修改一个正在运行的副本。
5. 停止终端，进入任务标签的“Git 变更”，读取差异、暂存、逐文件核对并创建本地提交。
6. 使用项目原有快照、验证、预览、成果和远端交付功能。受保护的整合 / 合并仍要求既定评审；单人不自动绕过团队策略。
7. 需要继续编辑时，从新快照打开草稿，或复制已交接草稿。需要带回本机时下载整个工作文件夹 ZIP。

## 语义开发工具补齐（2026-09-25）

已实现并接入真实编辑器：

- JS / TS / JSX / TSX 的跨文件语义补全、类型悬浮提示、语法和类型诊断、定义跳转（F12）、引用查询（Shift F12）、文件符号（Ctrl / ⌘ Shift O）。诊断展示在“问题”列表并标记到代码；点击问题跳至行列。请求使用当前编辑文本覆盖已保存草稿，过期结果丢弃。
- 符号重命名（F2）、整理导入、当前位置快速修复（Ctrl / ⌘ .）。重命名遵循 TypeScript 的绑定语义：在导出声明重命名时更新引用，在导入别名上操作时保留相应别名语义。修改先展示涉及文件的 Diff，由用户确认。
- 共享草稿跨文件替换：字面量匹配、区分大小写、全词匹配，替换字符串按字面插入。最多 40 个修改文件；超过限制直接拒绝，不提交截断结果。二进制和大文件跳过并标注数量。
- 重命名、整理导入、快速修复和替换共用原子写入通道。事务内重新授权、锁定草稿、检查预览版本及每个文件基线，再更新 Yjs 与文件内容；任一不符整批回滚。可立即撤销该批修改；其他成员已继续修改时，撤销也会拒绝过期版本。
- 格式化查找最近一层 `.prettierrc` / JSON / YAML 或 `package.json.prettier`；支持常用选项和按文件 `overrides`，保存回执明确配置来源。可执行配置 / 插件不运行并显示原因。仍通过既有最新版本检查与三方合并保存。
- 编辑器偏好：12–20px 字号、2 / 4 / 8 位缩进、Tab / 空格、自动折行。当前浏览器持久化，其他成员偏好不受影响。
- Ctrl / ⌘ P 快速打开当前草稿文件，过滤已删除文件；支持搜索路径、方向键选择和 Enter 打开。
- 文件标签拖动排序，焦点在标签上也可用 Alt Shift ← / → 排序；顺序随既有工作区标签持久化。
- 复制已交接草稿后保持编辑模式，不再退回仓库只读浏览。

实现边界：语义服务目前是 TypeScript LanguageService，不是通用 LSP 宿主。它只读取已授权的草稿和随应用安装的 TypeScript 标准类型，不访问其他项目、本机任意文件或执行仓库插件。支持当前 `tsconfig.json` / `jsconfig.json` 的常用 compilerOptions 与 paths；暂不展开 extends / references，也没有自动安装依赖包类型。限制 300 个源码 / JSON 文件、4 MiB；缺失的依赖会成为正常的“无法找到模块”诊断。诊断当前文件，跨文件查询在该受控项目内运行。格式配置未覆盖 EditorConfig、Prettier 插件或可执行配置。批量撤销只保留当前预览会话，不等于全局文件操作历史。

验收：27 项相关自动测试通过（13 项真实数据库编辑 / 权限 / 并发测试，9 项语言服务测试，2 项格式配置测试，3 项文件标签状态测试）；类型检查、lint 和独立副本生产构建通过。Chrome 真实操作已完成导入类型错误检测、从引用跨文件跳到定义、两文件符号重命名、两文件撤销、跨文件替换、拼写快速修复、Ctrl / ⌘ P 打开文件、标签排序、字号持久化、类型补全及项目格式配置保存。补全实际返回导入数值的 `toFixed` 方法，接受并保存调用后诊断清零。格式化将双引号 / 分号调整为 `.prettierrc.json` 指定的单引号 / 无分号，回执与文件内容一致。未调用模型，未推送远端。

## 与完整 Cursor 仍不等价的能力

以下尚未完成，不能用“可以在终端做”代替对应 IDE 功能：

- 多语言 LSP、依赖类型安装与项目引用、完整重构 / 代码操作覆盖。当前新增的语义能力以 JS / TS 和受控草稿为范围。
- 可视化调试：断点、单步、调用栈、变量 / watch、调试配置与 DAP 会话。
- 不同文件的可编辑分栏、完整自定义键位、全局文件操作撤销历史。已完成标签排序、快速打开、常用编辑偏好与多文件修改批次撤销。
- AI 行内预测补全、选区直接重写、任意多文件上下文附件和服务端完整长期对话。当前单文件 AI 及隔离的多文件任务保持现有工作流。
- 本机持久目录直接编辑 / 运行 / Git 的统一工作区；完整本地 Git 历史导入；SSH、WSL、Dev Containers。
- VS Code 扩展宿主、Test Explorer 与对应语言 / 框架插件。
- 独立个人项目策略；现有团队受保护整合仍要求独立评审。

## 后续开发顺序和验收门槛

2. TypeScript 语义通道与多文件原子确认已完成第一阶段；继续扩展多语言 LSP、依赖类型和项目引用。
3. 在已有运行和控制权生命周期上增加 DAP 调试服务，固定项目、运行、工作目录与端口权限；重连、控制权交接、撤权和停止都要有测试。
