# 共享人工终端

任务页「运行方式」可以选择「共享人工终端」。它创建受管理的新工作区并打开真实 Bash PTY，不调用模型。项目成员共享输出，当前控制者拥有输入权。默认仍为 AI 执行。

## 主流程

1. 选择仓库基线，或停止 AI 后保存的代码快照。需要应用人工共编内容时，先冻结草稿并选择该版本。
2. 选择「共享人工终端」并打开。它遵守任务运行、依赖、资源与共编交接检查，同一任务不能同时有 AI 与人工终端写入。
3. 当前控制者可以使用命令框发送整条命令，或勾选直接键盘输入后使用终端。支持 Ctrl+C、交互程序及显式 PTY 行列调整。
4. 其他成员旁观，使用现有「会话控制与交接」申请输入权。当前控制者或维护者同意后，新控制者继续同一个 shell、目录和进程；旧控制版本不能再输入。
5. 执行 `exit` 或使用运行的停止按钮。执行器核验 shell 会话内的普通后台作业及监督进程均退出后才释放工作区。
6. 保存终端运行快照，随后选择 AI 执行从该快照创建新工作区。沿用现有固定验证、成果发布及 Git 交付流程。

每位旁观者的字号和窗口高度独立保存在该浏览器中，不改变别人的页面。PTY 的行列数属于共享进程，只由当前控制者明确调整，调整事件同步给所有查看者。

## 权限、持久记录与退出

终端使用原有项目角色、MFA、运行控制版本、持久输入队列和幂等键。输入投递结果未知时不自动重放，控制权交接也会被未核实的投递阻止。交接取消旧控制者尚未投递的输入；已经交给 shell 的字节可能继续执行，交接不会撤销命令。

命令、原始键盘输入及输出对授权项目成员可见并保留在项目记录中。终端不注入模型凭据或控制平面的数据库凭据，使用独立 HOME 和固定环境。浏览器拒绝通过终端 OSC 52 控制剪贴板，不自动打开输出中的链接。

监督进程记录 PTY 会话标识。正常停止检查整个会话，而非只检查 shell 父进程，后台作业及单独作业进程组也必须退出。启动中断、丢失身份或退出不能确认时维持隔离，不能把未知状态当作已停止。

## 安装与基础范围

首版提供原生 macOS/Linux 共享终端，依赖 Bash、项目内 node-pty 原生模块与 Python 3。Python 仅以 `-I -S` 隔离模式读取 POSIX 进程会话；macOS 的 `ps sess` 会被系统隐藏，因此不能用它伪造会话退出证据。启动前检查可用性，缺少依赖则显示运行失败。

原生版本延续可信本机团队的运行边界，不是针对敌意 shell 命令的 OS 沙箱；主动脱离会话的守护进程不在此版普通作业保证范围内。Docker 终端尚未接入，仍保留在可选容器版本的补齐范围中。

单次输入最多 8192 字符，原始输入缓冲最多 32 KiB；共享运行默认最多 4 小时。输出经数据库和现有 SSE 同步，页面重连重放最近 100 批，较早屏幕可能不完整，页面明确提示；完整终端屏幕快照及长历史检索属于后续增强。界面本地待发送请求不会跨关闭页面恢复。
