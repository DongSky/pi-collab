# 固定检查点的独立静态预览

迁移 054 提供一个可实际交互的预览基础流程：从通过验证的不可变快照，复制指定目录的 HTML/CSS/JS/图片/字体，供项目成员在独立来源的浏览器沙箱查看。无需给评审者任务终端权限，不写回源工作区，不启动项目服务端或安装依赖。

## 操作

1. 在代码中准备 `preview/index.html` 及其相对引用的静态资源。先运行、创建快照并通过固定验证。
2. 在任务页“检查点独立预览”选择通过的验证，填写静态目录和 HTML 入口，创建预览。
3. 项目成员点击“打开独立预览”。每人领取独立的 5 分钟访问能力，预览文件保留 1 小时；到期可在预览尚有效时重新打开。
4. 作者或维护者填写说明后撤销预览。随后资源请求立即拒绝，页面在刷新状态后关闭 iframe；访问日志保留，独立复制文件由网关每分钟回收，源快照和工作区保留。

允许开发者、评审者和维护者创建；项目读成员可查看。访问能力绑定当前成员权限版本，每次资源请求前后重新检查。退出项目、成员停用、预览撤回、访问能力到期后不能继续读取。访问 URL 是个人短期凭据，不写入日志或普通项目列表。已下载的字节无法远程收回。

每项目最多 20 项活动预览，每项最多 200 文件、8 MiB。快照已有的秘密文件/软链接排除规则仍适用；临时预览只保存清单内的固定字节，不注入宿主或生产凭据。`dist`、`build` 等生成目录被快照规则排除，待评审产物应显式保存到 `preview` 等可快照目录。

## 来源隔离与部署

本机控制台默认 `http://127.0.0.1:30142`；预览通过现有独立网关的 `http://127.0.0.1:30143/preview/...` 提供。网关不采用浏览器 Cookie 鉴权、不设置 Cookie，也不转发 Cookie。页面同时有 iframe sandbox 和响应 CSP sandbox，不允许同源权限；脚本不能读取控制台 Cookie、存储或父窗口。

外部网络请求、表单、子 iframe 和服务工作线程禁用。仅允许自身静态资源和内联脚本/样式。网关的模型接口依旧要求独立运行能力并拒绝浏览器 Origin，预览能力不能调用模型。

部署时 Web 配置 `PI_COLLAB_PREVIEW_ORIGIN` 为与 `BETTER_AUTH_URL` 不同的 HTTP(S) 来源；网关配置 `PI_COLLAB_WEB_ORIGIN` 为控制台来源，以限制 frame-ancestors。生产建议使用独立预览域名、HTTPS 和只将 `/preview/` 和 `/service/` 反向代理到网关。没有配置或使用控制台同一来源时拒绝创建/打开。这里只实现配置支持，未宣称公网部署验收完成。

## 验证与边界

2 项专项使用真实 Pi 无推理执行、快照和固定验证，确认源工作区后续修改不影响预览、秘密文件不可读、路径隔离、权限撤销、访问日志、过期清理和失败反馈。双成员网页验证交互、各自独立页面状态、独立来源、浏览器实际阻止 Cookie 访问、撤回及桌面/390px 布局。

静态预览保留上述限制。迁移 060 另行接通 [动态服务预览](service-previews.zh-CN.md)，支持从固定快照安装/构建/运行 Node/npm HTTP 服务，并提供实际输出与访问日志；原生和 Docker 共用权限及停止回收流程。WebSocket、长流式响应、应用 Cookie 与生产数据库仍在后续扩展范围。
