# 公开版本脱敏说明

日期：2026-09-26。

首个公开版本从经过检查的源码快照建立独立 Git 历史。开发阶段的提交作者信息、旧文件版本、配置和截图不随首发上传；MIT 许可证、上游版权及派生来源保留。文档中的仓库所有者仅用于明确指定的公开仓库地址。

保留旧开发历史的本地仓库不能直接向公开仓库推送所有分支或标签。后续公开开发应基于远端 `main`，不要将旧私有开发分支合并进公开历史，也不要使用 `git push --all` 或 `--mirror` 发布它。

本次处理包括：

- 将本机用户名、绝对路径和个人模型供应商选择替换为通用说明；演示模型改为由调用者显式指定。
- 将文档中的本地验收 UUID 替换为示例标识，保留测试范围和结果说明。
- 移除旧会话 / 桌面截图及其嵌入引用；应用图标不含 PNG 文本或 EXIF 元数据。
- 排除运行数据、Pi 配置、环境配置、日志、密钥、数据库和测试产物；仅保留无真实凭据的部署模板与合成测试样本。
- 使用 Gitleaks 扫描源码和提交历史，并在本机将已配置凭据的值与源码比对。比对过程不打印或保存凭据值，扫描报告不加入公开仓库。

示例邮箱使用保留的示例 / 测试域名。输出脱敏测试需要模拟令牌、连接串和私钥边界，这些是人工构造的测试数据，不是可用账户凭据。

后续提交应继续检查新增文件及提交历史，特别是截图、日志、导出的会话和环境文件。仓库的 `.gitignore` 用于减少误提交，不能替代凭据扫描。

本说明记录首发前的检查方法与边界，不代表对后续修改的持续安全保证。
