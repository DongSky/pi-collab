## 当前边界，后续验收需关注

- 目录导入目前是受控副本；ZIP 导出不回写来源目录，也不携带完整 Git 历史。项目可在侧栏「本地目录关联」中显式绑定服务端可访问的本机目录，绑定后保存自动三方合并回写（见 code-workspace「本地目录关联」一节）；未绑定的导入副本仍不回写。
- 语义服务目前是 TypeScript LanguageService，只读取授权草稿和随应用安装的标准类型；上限 300 个源码 / JSON 文件、4 MiB。不是通用 LSP。
- 诊断针对当前文件；暂不展开 tsconfig extends / references，也不自动安装依赖类型。
- 批量变更最多 40 文件；撤销只保留当前预览会话，不是全局历史。
- 搜索 / 导出范围上限 2,000 文件、32 MiB；文本搜索跳过大于 256 KiB 的文件，结果最多 200 处。
- 文件聊天保留本窗口最近 10 个对话，下一轮携带最近 4 条消息摘要；不是服务端完整长期会话同步。
- 格式配置暂不支持 EditorConfig、可执行配置及 Prettier 插件。
