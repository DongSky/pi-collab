# ADR-047：显式下载不可变 PR 代码版本

状态：已实现；迁移 033。日期：2026-09-23。

## 问题与决定

PR 状态观察只有 head/base 提交身份，不能让成员核对具体代码，也不能充当后续 CI 或评审的代码依据。新增独立的持久代码下载作业，以最近一次成功的显式观察为输入。页面读取历史不访问 GitHub；具有当前任务控制权限的成员明确点击下载后，Git broker 才申请单仓库 contents:read 令牌。

下载输入固定 change、repository、PR ID/number、observation ID/hash、head/base SHA 和分支名。通过 upload-pack 取得准确提交及完整历史，以唯一 merge-base 到 head 计算差异。来源分支移动不会把请求替换成最新提交；提交不可取得、无共同祖先或多个共同祖先时失败。没有 receive-pack、checkout、项目代码执行、分支更新、评论、评审或合并副作用。

## 权限、持久性与故障处理

- 数据库接纳固定任务版本、观察版本、组织/项目授权版本、安装及仓库关联；幂等键绑定原请求，项目最多 20 个活动作业。
- Git 角色只能调用领取、开始、存活检查和完成函数，不能直接读取凭据表、作业表或写最终状态。领取使用固定数据库连接、session advisory lock 与 claim nonce。
- 下载期间检查当前授权；发布前再次锁定用户、任务、安装、关联和 PR 记录。取消、撤权、任务变更、新观察或关联变化均拒绝旧结果发布。
- 下载完必须撤销临时令牌；完整校验 Git pack、对象、引用、清单 SHA-256 后，数据库独立核对清单输入、字节摘要和只读 transport evidence。
- 连接丢失后原作业记为失败，不能自动重新下载。已提交但响应丢失时重复请求返回原 ready 记录。旧失败目录不重用；新请求分配新目录。
- 成功版本不被新观察覆盖。版本列表标示是否仍对应最近成功的本地观察；这不代表实时远端状态，也不代表检查、审批或合并通过。

## 文件读取与界面

通过受项目身份保护的接口读取固定目录，前后重新检查访问权限。清单摘要从数据库取得，浏览器不能选择磁盘根或信任自己提供的摘要。每次读取校验完整产物，异常返回不可用而不重新下载。

列表每页 100 个路径；逐文件请求必须匹配 diff hash 和清单内准确路径。只显示普通文本，代码作为文本渲染，控制字符转义；秘密路径、疑似凭据、链接、子模块、二进制及超限内容明确显示排除原因。普通文本显示上限 256 KiB、8000 行；底层产物单文件上限 2 MiB、pack 64 MiB。元数据、可执行位和删除仍记录于固定清单。

两名成员共享下载状态、固定差异及历史记录。浏览器保留原幂等请求，网络失败后重试同一操作，不用新编号掩盖未知结果。

## 验收与边界

集成测试使用真实 PostgreSQL、Pi 工具产生的提交和回环 smart HTTP Git：并发接纳/领取、准确 diff、路径/hash 拒绝、跨项目拒绝、取消、旧观察、成员/任务/安装/绑定变更、SQL 所有权丢失、清单篡改与受限 SQL 校验。浏览器验证双成员差异、响应丢失重试、秘密/二进制排除、CSRF、桌面和 390px 布局。

未以回环测试冒充真实 GitHub 安装验收。签名 webhook、可信 CI、远端版本评审与受保护合并继续属于 M3-02 后续工作。下载历史的保留/回收和性能优化需纳入部署容量验收；完整产物校验优先保证当前读取可靠。
