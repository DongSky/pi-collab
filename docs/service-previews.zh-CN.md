# 动态服务预览

任务页「检查点独立预览 → 动态服务预览」可以从通过验证的快照创建 HTTP 服务。迁移 060 接通配置、队列、安装/构建/启动、成员访问、输出与 HTTP 日志、停止及临时副本回收。默认原生；Docker 来源固定继续 Docker，不降级运行。

## 使用流程

1. 在仓库中准备服务代码和必要的依赖锁文件，让服务监听 `HOST` 与 `PORT` 环境变量。保存快照，并完成固定验证。
2. 开发者或维护者选择通过的验证，填写名称、安装方式、可选构建步骤、启动程序/参数、健康检查路径与最长运行时间。
3. 选择 npm ci 时，要求快照中有 package.json/package-lock.json，禁用安装生命周期脚本，拒绝项目 .npmrc，使用独立空 npm 配置与缓存。构建步骤及启动参数为参数数组，不经过 shell 拼接。
4. 明确确认执行项目代码以及停止后回收临时数据，提交后可查看排队、安装/构建/启动、运行中及失败状态。
5. 成员点击「打开动态预览」，每人获得绑定权限版本的 5 分钟访问能力。服务自身最长运行 30–3600 秒，默认 900 秒；作者或维护者填写原因后可提前停止。
6. 停止、到期、作者权限变化或执行器失联后终止服务。只有确认原生进程会话或容器退出，才删除临时副本；源快照及 AI 工作区不变。未知结果继续占用端口和额度，执行器只核查退出凭据，不重新启动原请求。

Node 启动参数示例：`["server.js"]`。npm 启动参数示例：`["run","start"]`。构建示例：

```json
[{"tool":"npm","args":["run","build"],"timeoutSeconds":120}]
```

安装/构建会真实执行项目代码，沿用原生可信团队与 Docker 容器的既有信任边界。没有模型推理，不注入 Web、数据库、邮件或模型凭据。原生服务只约定绑定分配的回环端口，不声称具备 OS 网络沙箱；Docker 保持 network=none，包安装通过已有 npm registry 桥接。

## HTTP 与浏览器边界

外部入口为独立预览来源的 `/service/<个人短期能力>/`。网关不直接接受任意代理主机/端口，而是将已授权请求交给对应执行器，再经受控 JSONL 通道请求服务所在运行环境的固定回环端口。Docker 不发布容器端口、不挂载 Docker socket。

支持 GET/HEAD/POST/PUT/PATCH/DELETE；OPTIONS 在验证访问能力后由网关处理。请求只传方法、路径、Content-Type 与 body，控制台 Cookie、Authorization、代理头和个人访问 token 不传给服务。响应不透传 Set-Cookie 或服务端 CSP，绝对站内重定向改写为当前能力路径；外部重定向拒绝。短期能力不得分享或记录到公网代理日志。

页面保持独立来源及不允许同源的 iframe/CSP sandbox。允许脚本通过相对地址调用预览 HTTP 接口；服务应使用相对资源/接口地址。浏览器不能读取控制台或预览 Cookie。没有服务工作线程、子 iframe、表单提交权限；响应 Cookie 不构成应用登录状态。

当前为短 HTTP 请求预览：请求最多 1 MiB、响应最多 2 MiB、服务响应约 8 秒、代理等待最多 12 秒；不支持 WebSocket、SSE、长流式响应、应用 Cookie、任意根绝对资源地址或生产数据库。超时的写请求结果可能不明，不自动重试。HTTP 日志只保存方法、去掉查询串的路径和状态，最多 100 条；中转 body/response 定期回收，不作为业务记录保留。

## 运行与治理

每项目最多 4 个排队/活动/待核查预览；单执行器最多同时管理 4 个。分配与已有工作区不重叠的 61000–61999 端口，启动前检查占用。固定副本复用快照恢复、依赖/契约/修复输入和原有原生/容器退出凭据。

副本启动前按项目工作区额度在产物预算中预留，执行时约每 2 秒计量，超额或计量未知请求停止。副本是创建时明确确认的短期数据，退出确认后自动清理，不套用长期候选成果的 90 天保留期。退出未确认或清理失败继续保留用量。运行输出保存末尾 16000 字符，总输出超过 8 MiB 会终止服务。

服务队列纳入运维排空。排空期间可请求停止已有预览；未知执行仍会阻止把实例标记为已排空。更新 Docker runner 后再启动容器服务；原有 AI、终端协议保留。Caddy 模板新增 `/service/*`，模型/协调入口仍不对公网开放。

## 验证

原生/Docker 专项使用真实 Pi 工具准备快照、真实固定验证、空依赖 npm ci、构建和实际 HTTP 服务，覆盖 GET/POST、预检、重定向、凭据头剥离、权限撤销、启动失败、到期、退出确认、文件回收和未知租约不重放。浏览器专项使用实际常驻 executor，验证两名成员对同一后端服务进行交互，并检查独立来源、Cookie 隔离、CSRF、停止回收及桌面/390px 页面。无外部推理或公网部署。
